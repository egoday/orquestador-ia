# Tareas

Todavía no se ha iniciado ninguna tarea con este orquestador.
Cada tarea tendrá su propia carpeta `yyyyMMdd-slug/` y un `estado.md`.
Los documentos del flujo original no se importan automáticamente.

Si se exporta el plan con el agente independiente `testlink-exportador`, la tarea
puede contener una carpeta `testlink/` con el XML y el informe de conversión. Esa
exportación no modifica el estado ni forma parte del flujo de fases.
